# IKS Atlas

An easy way to find Indian Knowledge Systems references for Classes 9 and 10.

## Download 0.2.0 public beta

- [Windows Setup EXE](https://github.com/aishKodes/IKS_AI-Releases/releases/download/v0.2.0/IKS-Atlas-Windows-Setup-v0.2.0.exe)
- [Windows portable ZIP](https://github.com/aishKodes/IKS_AI-Releases/releases/download/v0.2.0/IKS-Atlas-Windows-Portable-v0.2.0.zip)
- [Android APK](https://github.com/aishKodes/IKS_AI-Releases/releases/download/v0.2.0/IKS-Atlas-Android-v0.2.0-public.apk)
- [Release notes and checksums](https://github.com/aishKodes/IKS_AI-Releases/releases/tag/v0.2.0)

Anyone can download these files without a GitHub account. Install, open the app, choose class, subject, topic and subtopic, then tap **Find connections**. Direct concept search also works. The full database and fonts are included; no source-file import, data download, account, server or AI key is needed.

The collection includes **136 reviewed research mappings** covering Biology, Chemistry, Economics, Mathematics and Physics across Classes 9 and 10. The corpus owner confirmed review and professor authorization for public distribution. Exact original references are retained; linked resources have not been checked. Historical connections do not imply scientific equivalence.

## Installation and test status

Windows Setup supports Windows 10/11 x64 and includes runtime DLLs. For the portable version, extract the whole folder before opening `iks_atlas.exe`. The Windows installer is unsigned and may trigger SmartScreen; verify the SHA-256 checksum. It has been built, installed into a fresh Windows profile and launched offline with the actual new interface. Complete native desktop interaction acceptance is still being completed; physical Windows 10/11 testing remains outstanding.

Android may ask you to allow APK installation from your browser or file manager. The universal APK uses the same persistent signing key as the earlier pilot and passed 33 fresh offline emulator checkpoints. Physical phone/tablet testing remains outstanding.

## A simpler interface

Choose-first layout, readable bundled Manrope typography, colourful subject accents and clear reference cards. Primary navigation is **Find / Saved / More**; extra research and teaching tools are available when needed. Bookmarks, notes and edited teaching material stay on-device.

## Availability and rights

This repository provides public app downloads. Source development remains in a separate private repository. Original research documents, private authoring data and credentials are excluded. Dataset ownership remains with its research rights holders; permission to download the app does not grant unrestricted corpus republication rights. Installed structured records can be extracted.

Optional AI needs your own provider key and explicit sharing authorization. It is not required for lookup or offline teaching templates. No public editorial server is required.
